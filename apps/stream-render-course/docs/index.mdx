# 不把 Streaming Render 当黑盒

这不是一套“看完就算会了”的概念文章。你会维护一个很小的 React Chat，让同一条回答依次经历最笨但正确的 M0、按帧提交的 M1，以及带局部解析与重型节点保护的 M4；每一次优化都由失败现象、测试和浏览器指标推动。

> 适合已经会 TypeScript、React、Promise 和基础 HTTP，但还没有系统处理过流式协议与增量渲染的前端工程师。

## 学习方式

每章都要求你先运行一个会失败的 exercise，再只增加一个能力。不要先复制 solution；先写下你预测的事件序列或 commit 数，再运行测试。预测与结果不一致的地方，才是这套课程真正有价值的部分。

```bash
pnpm install
pnpm dev:stream-render
pnpm --filter stream-render-lab lesson quick-start test
```
