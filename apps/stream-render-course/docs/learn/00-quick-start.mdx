# 为什么回答可以不用等完就出现？

同一份回答，两种显示方式。你不需要先理解网络协议，先看一次结果。

**约 5 分钟 · 无需 API Key · 这一课不写代码**

## 第一步：先猜一下

假设一份回答需要两秒才能生成完：你愿意看着空白等两秒，还是先读已经生成的部分？

完整返回会等所有文字准备好再显示；流式返回会把已经准备好的部分逐步交给你。

## 第二步：运行对比

点击 **运行对比**。注意左右两边第一次出现文字的时机。也可以点 **单步**，每次只推进一段。

<LessonDemo demoId="first-look" presetId="first-look" />

这里使用固定文字和模拟时间，不调用真实模型。实验里两种方式的最终内容和完成时间相同，区别是你什么时候可以开始读。

## 第三步：用自己的话解释

先暂停，再试着回答：

1. 左边还在等待时，右边为什么已有文字？
2. 右边提前出现文字，能证明模型生成整份回答更快吗？
3. 两边最终应该出现不同的回答吗？

## 第四步：准备亲手实现

接下来会先做一次完整返回，再让文字分段出现。你只需要会变量、函数和数组；遇到异步代码时，可以先读 [JavaScript 预备知识](/basics)。

准备写代码时，按 [环境安装与运行](/setup) 启动 Course 和 Lab。若实验一直显示正在加载，请确认两个服务都已启动，且没有混用 localhost 和 127.0.0.1。
