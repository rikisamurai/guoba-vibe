# QR Vault docs

This folder contains the standalone project introduction page for QR Vault.

## Files

- `index.html` is a static Chinese introduction page for the project. It explains what QR Vault is, why it is local-first, how sharing works, and how to start the app locally.

## Preview

Open `index.html` directly in a browser:

```bash
open apps/qr-vault/docs/index.html
```

No build step is required. The page is self-contained and does not depend on the QR Vault app bundle.

## Notes

- Keep this page focused on product introduction, not implementation docs.
- Keep screenshots and visual assets embedded or colocated with this folder.
- For app setup and development commands, update `apps/qr-vault/README.md`.
