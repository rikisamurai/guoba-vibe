为什么用它

适合日常调试和分享链接

用于整理调试、测试和分享中反复使用的 URL，减少重复复制和手动改参数。

01

同一批 URL 反复用

粘一次、起个名、归到分类里，之后随时复制原始 URL、分享 URL 或生成二维码，不用每次手敲那段长长的 xhsdiscover://…。

02

URL 可以直接分享

每个条目都能生成独立 hash 分享页，把 URL、标题、描述放进分享 URL；对方点开即可扫码或保存到自己的本地库。

03

本地保存

数据全写进 localStorage，源码里没有任何 fetch / axios，字体也走 bundle 不连 CDN。重新打开页面后仍可继续使用。

主控台

你的 URL / QR 主控台

  • 双栏布局：左侧列表，右侧详情显示选中条目的二维码、原始 URL 与分享按钮。
  • 分类筛选行：All QR / Uncategorized / 各个分类，都带数量徽标。
  • 多维搜索：同时匹配标题、描述、链接、scheme、path 以及任意 query 的键 / 值。
  • 删除有后悔药：删除按钮第一次点是“待确认”，3 秒内再点才真删；删完提示里还有 Undo，连原分类归属一起恢复。
URL 编辑器

改一个 query，二维码即时刷新

  • 三视图双向同步：完整链接文本框、scheme + path 输入框、query 参数 行表格，改任一个其余跟着变。
  • 任意 scheme 都能解析：不限 http(s)，xhsdiscover://、myapp:// 等自定义协议都能正确拆开。
  • 即时二维码预览：链接校验通过才渲染；非法时显示占位 + Awaiting valid URL，不会出“假二维码”。
  • 另存为新条目：在已有条目上改完，可选 Save as New 另存，不覆盖原版本。
Query Params

参数可开关，不删值也能试链路

  • 每行独立启用：query 参数行自带开关，临时关闭不用删 key / value。
  • 只回写启用项：关闭的参数保留在表格里，但不会参与完整 URL、解析详情和二维码。
  • 分享同步变化：启用状态一变，右侧二维码和可分享 URL 会跟着刷新，发送前可以先确认实际生效的参数。
分类管理

按场景把链接归归类

  • 三栏布局：左 = 所有分类，中 = 新建 / 编辑表单，右 = 当前分类下的二维码列表。
  • 多对多归属：一个二维码可进多个分类，详情页用多选器一次性管理。
  • 路由直达：/#/collections/<id> 直接进某个分类的子视图，链接可分享。
可分享 URL

复制一条 URL，对方直接打开

  • 参数走 URL hash：分享链接形如 …/#/share?url=…&title=…，URL hash 不会发到服务器，数据不上云。
  • 接收方落地页：二维码大图 + 解析详情 + Save to local 一键写入对方自己的库 + 复制原始 URL。
  • 明确标注：页面底部写着 Stays on this device. Nothing is uploaded.
导入 / 导出

换设备、做备份，一个 JSON 搞定

  • 导出：一键下载 qr-vault-export.json，含完整数据（二维码 + 分类 + 归属关系），丢 Git / 网盘 / U 盘都行。
  • 两种导入语义：Merge into local 按 id 增量更新、不丢已有数据；Replace 全量覆盖，有红字警告。
  • 严格校验：JSON 结构不合法直接报错，本地数据不会被破坏。
隐私与数据

数据只在本地

所有数据只写 localStorage，不会上传到服务端。

三个 localStorage 键

qr-vault:data 全量数据 · qr-vault:theme 主题 · qr-vault:onboarding-v1 引导状态。仅此而已。

无网络请求

源码里没有 fetch / axios，字体也打进 bundle，不连任何第三方 CDN。

分享链接提醒

数据虽不上传，但分享 URL 明文写在 hash 里，截图 OCR、聊天记录都看得到。含 token / 个人信息的 deeplink，别随手丢公共群。

快速开始

三十秒上手

大多数人直接打开链接就够了；想改源码的再往下看本地启动。

① 直接用（推荐）

打开链接即用，无需安装

# 打开页面，首次进入会自动注入
# 2 个分类 + 5 个常用站点
https://omni.xiaohongshu.com/site/qr-vault-310/

进去有四步引导（新建二维码 → 输链接 → 实时预览 → 保存），侧栏底部 ? 可随时重看。

② 本地跑（想改源码）

Node ≥ 24 · pnpm 11.3.0（corepack 已锁）

corepack enable
pnpm install
	pnpm --filter qr-vault dev   # http://localhost:5173

注意：仓库根 pnpm dev 不指向本应用；请用 --filter qr-vault 明确启动。
